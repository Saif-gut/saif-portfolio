Das Lernmodell

Weniger Vorgaben.

Eine Antwort erkennen und selbst eine Lösung schreiben sind zwei verschiedene Dinge. Das ist der Ausgangspunkt von Codegarten.

Code ausführen

Python über Pyodide und JavaScript laufen isoliert im Browser. HTML/CSS hat eine isolierte Live-Vorschau, SQL eine SQLite-Übungsdatenbank. Java, C# und C++ nutzen statische Codeprüfung, keine vollständige Nutzer-Runtime. Git und Linux sind Simulationen.

Fortschritt erhalten

Local-first-Speicherung, Gastmodus, optionale Accounts mit PostgreSQL, Offline-Nutzung nach dem Paketdownload sowie Backups und Synchronisierung. Konfliktlösung und idempotente Verarbeitung sollen Fortschrittsverlust und doppelte XP verhindern.

Lernen begleiten

XP, Levels, Streaks und Lernpfade motivieren. Mastery, Wiederholungen und Transfer-Aufgaben unterscheiden geführte Erfolge von selbstständiger Anwendung. Ein Nachweis der Lernwirkung mit echten Anfängern steht noch aus.

React · TypeScript · Vite · Pyodide · SQLite · PostgreSQL · Docker

02 / Über mich

Neugierig genug,
um anzufangen.

Saif Aldien Abbud ↗

Am meisten lerne ich, wenn ich etwas ausprobieren kann – und verstehen muss, warum es noch nicht funktioniert.

Ich habe mit eigenen Webseiten, Tools und Spielen angefangen. Mich interessieren sowohl die sichtbare Oberfläche als auch die Logik dahinter: Wie kommen Daten an? Wo werden sie gespeichert? Was passiert, wenn etwas schiefgeht?

Ich stehe am Anfang meiner beruflichen Laufbahn. Eigene Projekte geben mir praktische Erfahrung. In einer Ausbildung möchte ich die Grundlagen vertiefen und lernen, wie ein Entwicklungsteam gemeinsam gute Software baut.

Aus meiner bisherigen Arbeit kenne ich den Umgang mit Kunden und Kollegen. Absprachen einhalten, Rückfragen klären und Aufgaben selbstständig erledigen gehört für mich dazu.

So arbeite ich mit KI

ChatGPT, Codex und andere Coding-Agenten sind Teil meines Werkzeugsatzes. Ich formuliere Ideen und Anforderungen, entscheide über nächste Schritte, teste Ergebnisse und gehe Fehlern nach. Die Umsetzung entsteht mit KI-Unterstützung; die Entscheidungen und die Qualitätskontrolle gebe ich dabei nicht ab.

04 / Mein Weg

Ausprobieren.
Verstehen. Weiterbauen.

  1. Der Anfang

    Kleine Ideen umsetzen.

    Webseiten gestalten, Python ausprobieren und einfache Spielmechaniken bauen. Durch konkrete Aufgaben lerne ich die Werkzeuge kennen.

  2. Der Zusammenhang

    Systeme verbinden.

    Frontend, API und Datenhaltung zusammenbringen. Bei Spielen kommen Zustände, Regeln und Netzwerkverbindungen dazu.

  3. Der nächste Schritt

    Im Team besser werden.

    Von anderen lernen, Code gemeinsam besprechen und verstehen, wie Projekte auch langfristig verständlich und wartbar bleiben.
