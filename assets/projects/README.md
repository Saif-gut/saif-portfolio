# Projektbilder

Lege hier später die finalen Projektbilder ab. Die Portfolio-Cards verwenden aktuell bewusst beschriftete CSS-Platzhalter, damit keine leeren oder kaputten Bilder angezeigt werden.

Vorgesehene Ordner:

- `jarvis/`
- `bot/`
- `last-letter-club/`
- `bubble-pop/`
- `ausbildungs-assistent/`
- `java/`
- `portfolio/`

Empfehlung: pro Projekt ein optimiertes Querformat-Bild (mindestens 1200 × 675 px) als WebP oder JPG ablegen und danach die jeweilige Card in `index.html` auf das Bild umstellen.
